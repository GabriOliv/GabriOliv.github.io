Portfólio de QA em forma de "ficha técnica": um arquivo de sujeito que abre rodando uma suíte de testes.

## O que tem na página

- **Ficha de abertura:** suíte de testes animada, perfil no estilo `qafetch` e tabelas de ferramentas, certificações e skills.
- **Stack:** ferramentas em anéis, do código de teste à infraestrutura.
- **Certifications:** árvore de certificações por pré-requisito.
- **Projects:** projetos com link para o site publicado ou o repositório.
- **Gists:** gists públicos.

Tema claro e escuro, feito para celular primeiro.
